## 🇨🇳 中文

在三维导演台里，把简报、镜头表、参考图或已有场景排练成可编辑的三维预演。它按环境、主要体块、前景物件、角色、机位的顺序建场，退出条件是静态场面可读：朝向正确、脚或坐姿有支撑、剪影分离、背景能交代地点；随后安排机位路径与动作时间线，并逐帧看图检查剪影、比例与接触、互动关系、构图与纵深。交付可编辑场景、场面调度、角色姿态、机位运镜与镜头截图。属于前期预演，不承诺最终渲染品质或完整成片，也不替代你选定的 Blender 工程、平面分镜图或其他软件。

### ✨ 能做什么

- 输入场景简报/镜头表/参考图 → 输出可编辑三维预演场景与镜头截图
- 按环境 → 体块 → 前景物件 → 角色 → 机位顺序搭建，先可读再加细节
- 机位先定「这次揭示什么」再排路径，主体动作与机位围绕同一节点对齐
- 白模先过检查再原位细化，不用装饰遮掩布局错误
- 时间线改完按开始/中间/结束/切镜/空档逐帧看图，并排比较找滑步与遮挡
- 续改时保留无关物体、机位与既有时间线，只替换本次请求中被替代的旧内容

## 🇬🇧 English

Rehearses a brief, shot list, reference image or existing scene as an editable 3D previz inside a director stage. It builds in order — environment, main volumes, foreground objects, characters, cameras — and only exits once the static scene reads correctly: right orientation, supported feet or seat, separated silhouettes, a background that establishes place. It then plans camera paths and motion timelines and inspects rendered frames for silhouette, proportion and contact, interaction, composition and depth. It delivers an editable scene, blocking, character poses, camera moves and shot screenshots. This is pre-production previz: it promises no final render quality or finished film, and it does not replace your chosen Blender project, flat storyboards or other software.

### ✨ What it does

- A scene brief, shot list or reference image in → an editable 3D previz scene plus shot screenshots out
- Builds in order: environment → volumes → foreground objects → characters → cameras; readable first, detail later
- Camera work starts from what each shot reveals, with subject motion aligned to the same dramatic beat
- White-box checks before in-place refinement, so decoration never hides a layout error
- After timeline edits it inspects start, middle, end, cut points and gaps, comparing adjacent frames for foot slide and occlusion
- Edits in place, keeping unrelated objects, cameras and existing timelines intact
